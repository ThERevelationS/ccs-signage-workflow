## CMP-SUP-005 - Dayton Superior SBU Slab Bolster Upper Tech Data Sheet

- Authority: Dayton Superior, manufacturer.
- Source type: public product technical data sheet.
- Title: SBU - SLAB BOLSTER UPPER Rebar Supports, Technical Data Sheet.
- Primary URL:
  https://www.daytonsuperior.com/docs/default-source/tech-data-sheets/sbuslabbolsterupper.pdf
- Retrieved and inspected: 2026-11-08; PDF downloaded and text-extracted.
- Edition/date: none shown.
- Access: public PDF. Permitted use as CMP-SUP-003.
- Verification: VERIFIED; one manufacturer-internal height discrepancy noted.

### Inspected Facts

- SBU is a continuous support used to hold one layer of steel above another
  and space them to the required distance; two runner wires plus a top
  supporting wire connected by legs.
- Product specification height 3/4" to 5" (the handbook text says 3/4" to
  3" - unresolved manufacturer-internal discrepancy; do not assume the
  deeper range without SKU-level confirmation).
- Installation (verbatim substance): when supporting one layer above
  another, place on the lower layer so the runner wires are perpendicular
  to the lower rebar; the upper rebar is then placed perpendicular on the
  top supporting wire. On soft material the same orientation is used,
  placing on the soft material instead of on the lower steel.
- Available plain, epoxy coated, galvanized; plastic-dipped runners.
  Approvals: ACI 315-99, ACI 318R-14, CRSI RB4.1-2022, CRSI Load Category
  200 lb, classes 1/1A/3.
- Ordering table shows 5 ft lengths at ~0.36-0.39 lb/ft; also a 1" x 20"
  piece listed at 0.74 lb.

### Allowed Use And Limits

- The SBU height models the CLEAR DISTANCE between the top of the lower mat
  and the underside of the upper mat - it is not a bottom cover value and
  does not reach the pour bottom.
- Perpendicular-orientation requirement (runners across lower bars, top
  wire across upper bars) constrains placement direction; an orthogonal
  upper mat direction is required for correct bearing.

## CMP-SUP-025 - Shop-authored estimating assumptions

- Authority: CCS shop estimating assumptions (O-103 / CMP-I02).
- Source type: SHOP assumptions corpus — the method-domain constants and
  shop-authored defaults the estimator carries (e.g., per-letter pricing
  sheet values, install-time assumptions). Registered so rules built on
  shop practice can cite an honest source class instead of pretending an
  external code.
- Entries:
  - Method-domain constants the estimator carries as shop defaults.
  - Shop-authored install/labor assumptions (crew sizes, time basis).
- Verification flag: CANDIDATE by definition — a shop assumption is never
  an external code or a verified engineering source.

### Allowed Use And Limits

- Any rule citing CMP-SUP-025 normalizes with `verified: "candidate"` and
  therefore can never reach `status: "active"` — shop assumptions document
  the basis but cannot gate counts or pricing.

## Register Status

These are initial manufacturer sources, not a completed reinforcement or
preliminary-engineering rule registry. O-102 and the remaining research gates
stay OPEN. Structural foundations still require review by a real engineer.

## Source Groups By Domain (O-102 / W-023)

The register's sources grouped by the rule domain they feed — derived from
`FOUNDATION_RULE_REGISTRY` (`register_id` on each rule's `source_ref`), so a
reader navigates by topic rather than the flat CMP-SUP list. Domains with no
cited source are the held seeds — the citation gap is named, never covered.

- `support.placement.spacing` — CMP-SUP-013, CMP-SUP-015, CMP-SUP-016, CMP-SUP-019, CMP-SUP-022 (spacing/count ceilings per bearing mode)
- `support.density` — CMP-SUP-013, CMP-SUP-014, CMP-SUP-019, CMP-SUP-021 (density/count caps)
- `support.substrate` — CMP-SUP-007, CMP-SUP-013, CMP-SUP-015, CMP-SUP-016, CMP-SUP-021 (member vs substrate compatibility)
- `support.compatibility` — CMP-SUP-003, CMP-SUP-010, CMP-SUP-013, CMP-SUP-021, CMP-SUP-024 (member-type vs support-kind)
- `support.bearing_mode` — CMP-SUP-003, CMP-SUP-005, CMP-SUP-009
- `support.catalog` — CMP-SUP-002, CMP-SUP-003, CMP-SUP-005, CMP-SUP-010, CMP-SUP-012 (per-SKU catalog modeling; `SUP-CAPACITY-HELD`/`SUP-HEIGHT-HELD` name the held capacity/height gaps)
- `support.geometry` — CMP-SUP-003, CMP-SUP-005, CMP-SUP-009, CMP-SUP-011, CMP-SUP-014
- `support.placement` / `support.placement.mat` — CMP-SUP-013, CMP-SUP-015 (bracing, plates, mat placement)
- `support.finish` — CMP-SUP-003 (coatings)
- `stock.placement` / `stock.splice` — CMP-SUP-015, CMP-SUP-017
- `tie.pattern` / `tie.wire` — CMP-SUP-013, CMP-SUP-014, CMP-SUP-015, CMP-SUP-016, CMP-SUP-017
- `clearance.cover` / `clearance.tolerance` — CMP-SUP-014, CMP-SUP-015, CMP-SUP-023
- `authority.marker` — CMP-SUP-018, CMP-SUP-020, CMP-SUP-024 (paid/authority markers, not usable spec text)
- Held domains (no cited source — the seed IS the gap): `method.sign_wind`, `method.footing`, `method.shaft`, `method.lateral`, `method.frost_depth`, `method.pillar_bar`, `method.base_plate`, `masonry.cap_detail`

## Authority Class Badges (O-103)

`foundationSourceAuthorityClass(id)` returns a source's class key;
`foundationSourceClassLabel(key)` renders the badge — citation displays surface
the class so a shop assumption never reads as adopted code.

- `local_code` — "Adopted local code"
- `structural_standard` — "Referenced structural standard"
- `engineering_guidance` — "Engineering guidance"
- `manufacturer_instructions` — "Manufacturer instructions" (the CMP-SUP corpus is mostly this class)
- `shop_assumptions` — "Shop estimating assumption" (CMP-SUP-025 and the
  design-basis fields live here — estimating conventions, never structural law)
