## Proposed direction — review before any UI changes

Keep the current compact toolbar and always-reachable filters. Preserve always-visible small column checkboxes and the horizontal visualizer/preview in the same column-management screen; never replace them with search-only controls or a wizard. Use restrained slate/white surfaces, clear typography, subtle row focus and selection, consistent amount/date alignment, and semantic urgency colors only where supported by trustworthy data. Keep Board cards compact with verified customer, estimate and follow-up fields, and preserve non-drag stage movement. Maintain mobile cards, accessible 44px targets and tablet-friendly density. Avoid animated KPIs, broad redesign and duplicate controls.

Before visual implementation, complete or explicitly mark blocked the authenticated phone/tablet/desktop acceptance matrix in docs/sales-pipeline-responsive-browser-acceptance.md, inspect authorized current screenshots, then make one narrow visual change per checkpoint. Do not publish without explicit request.
